# scala-exercises

《Functional Programming in Scala》课程练习，每个目录是一次作业，含实现与测试。

| 目录 | 内容 |
|---|---|
| `recfun/` | 递归：帕斯卡三角、括号配平、找零方案数 |
| `funsets/` | 用函数表示集合：并、交、差、过滤、forall、exists、map |
| `objetsets/` | 面向对象的集合：推文集合的二叉树实现与排序 |
| `patmat/` | 模式匹配：哈夫曼编码的构造、编码与解码 |
| `forcomp/` | for 推导：字谜（anagram）句子生成 |
